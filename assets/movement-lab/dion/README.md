# Dion Reference Assets

Dion is version controlled so every StrideOS contributor and agent can use the same inspectable character identity for Movement Lab, exercise, coaching, and educational imagery.

Read [`DION_CANONICAL_REFERENCE.md`](./DION_CANONICAL_REFERENCE.md) in full before creating or modifying any Dion asset. The canonical front, direct-left-side, and back images live beside it as `dion_reference_front.png`, `dion_reference_side.png`, and `dion_reference_back.png`.

Name new assets with `dion_<movement>_<view>_<position>_v<number>.png`, for example:

- `dion_bodyweight_squat_side_bottom_v1.png`
- `dion_single_leg_squat_front_bottom_v1.png`
- `dion_running_gait_side_midstance_v1.png`
- `dion_split_stance_lunge_side_bottom_v1.png`

Every generation must use at least one canonical PNG as an image reference. Never casually replace, overwrite, or reinterpret the canonical references; changes to canon require deliberate review and a version-history update.
