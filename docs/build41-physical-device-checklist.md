# Build 41 Physical Device Checklist

## Preset plans and schedule

- Activate Couch to 5K, 10K, Half Marathon, and Marathon.
- Confirm future schedule changes and completed history remains.
- Remove active goal and confirm completed Activity history remains.
- Confirm Today, Calendar, Running, Strength, and AI Coach agree on scheduled-session ID and prescription.

## Today

- Correct primary workout.
- Supporting workout shown separately.
- Exact deep-link: Start Run/Walk, Start Run, View Strength Workout.
- No generic Activity redirect for a planned strength card.
- AQI value/category or AQI unavailable state.
- Weather/AQI details sheet copy.

## Calendar

- Month, Week, and Day views.
- Run duration and run/walk ratio.
- HR/RPE target.
- Strength details show duration and exercise count.
- Perform Today / view actions are contextual.
- Current-day workouts are not Missed before the local day ends.

## Running

- Plan matches Calendar.
- Active matches Plan.
- Full run/walk prescription.
- Voice prompts for run/walk.
- HR voice coaching above/below/back-in-zone.
- Completion sync updates Today and Calendar.

## Strength

- Exact scheduled workout.
- Exercise list, sets, reps, load, RPE.
- Perform Today.
- Live Activity payload.
- Pause/resume/complete on device.

## Activity

- Fresh install empty state.
- No fake activity data.
- Completed activities appear after real logs.

## Intake

- Race date picker displays MM-DD-YYYY.
- Program start date picker displays MM-DD-YYYY.
- PR time picker uses hours/minutes/seconds.
- Training Preferences race dates display/edit as MM-DD-YYYY.
- Profile calibration PR dates display/edit as MM-DD-YYYY.
- Manual Log Workout date displays/accepts MM-DD-YYYY.

## AI Coach

- Keyboard dismisses on scroll.
- Full conversation scroll remains usable.
- Latest message and input stay visible.
- No raw Markdown syntax.
- No emoji in assistant responses.
- Exact session information appears in answers.

## Bottom navigation

- Exactly six tabs.
- Icons slightly larger.
- Labels slightly larger.
- No crowding/truncation on narrowest supported iPhone.

## Movement Lab marker editing

- Drag beyond prior radius.
- Move markers to all image quadrants and near each edge.
- Page does not scroll while marker is dragged.
- Save, Cancel, Reset.
- Coordinate persistence in portrait and landscape media.

## Live Activity and voice

- Running, run/walk, walking, hiking, cycling, skiing, snowboarding payloads.
- Preset strength pause/resume/complete in one deliberate tap.
- Duplicate tap suppression and pending state.
- HR voice cue smoothing and cooldown.
- Simultaneous hydration/fuel/run-walk/navigation/HR cue merging.
