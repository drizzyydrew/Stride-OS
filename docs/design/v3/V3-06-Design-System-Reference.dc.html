Design Principles

🎯 Coaching-First

Every interaction surfaces actionable advice. The AI coach's insights are as prominent as the data itself.

📈 Progressive Complexity

Dashboard is simple and welcoming. Detail screens support power users. Defaults to data you care about today.

🌍 Warmth & Trust

Sand, Sage, and Clay create an approachable, premium feel. Not cold. Not corporate. Like a real coach.

⚡ Performance Clarity

Key metrics are always visible. No hunting for numbers. Every readiness score, every HR zone, every insight is one tap away.

🔄 Responsive to Intent

Live tracking shows the map and pace, not settings. Post-run shows celebration and insight. Context matters.

Implementation Notes

Dark Mode (Primary)

V3 is built dark-first. This is the default experience. All screens use #0a0a0a base with #1a1a1a surfaces.

Light Mode

Light mode follows the same structure but uses warm beige (#EFE7DA) and muted earth tones. The same information hierarchy and spacing apply.

Element Radius

Shadows

V3 uses minimal shadows. Hierarchy is created through color and borders, not depth.

  • Phone: 0 20px 60px rgba(0,0,0,0.6)
  • Elevation: Border + subtle background color shift
  • Live Elements: Glow: 0 0 8px rgba(220, 192, 167, 0.4)

Motion

  • Standard Transition: 200ms ease-in-out
  • State Changes: Opacity + slight scale (toggle, button press)
  • Live Metrics: Smooth number transitions (no jarring jumps)
  • Navigation: Fade between major screens, slide for overlays

Component Inventory

Complete list of all screens and states in the V3 design system.

Core Screens (10)

  • Dashboard — Home screen with readiness, weather, action buttons, upcoming workout, recent activity
  • Training Calendar — Week view, upcoming workouts, intervals, form tips
  • Live Tracking — Timer, map, metrics, controls (Lap, Pause, Stop)
  • Strength Workouts — Exercise list with sets/reps, form tips, start button
  • Analytics — Charts, key metrics, performance insights
  • AI Coach — Chat interface, coaching bubbles, user messages
  • Movement Lab — Form recording, gait analysis, cadence, ground contact time
  • Activity Log — Workout history, filterable by type, detailed per-workout stats
  • Profile — User stats, training zones, achievement badges
  • Settings — Dark mode, training toggles, notifications, preferences

Onboarding (4 screens)

  • Welcome screen (Goals setting)
  • Training level assessment
  • Device setup (GPS, wearables)
  • Coach intro & feature tour

States Per Screen

  • Empty: No workouts yet, loading states
  • Loading: Skeleton cards, pulsing metrics
  • Live: Animated metrics, pulsing GPS marker
  • Error: Connection lost, data sync issues
  • Completed: Post-workout summary, celebration state
