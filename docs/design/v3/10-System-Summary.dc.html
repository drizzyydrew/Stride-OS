Implementation for Engineering

Design Consistency

  • All inline styles. No CSS classes or external stylesheets.
  • Dark mode default. Light mode as variant (all colors inverted appropriately).
  • Spacing via 4px base unit (xs: 4, sm: 8, md: 12, lg: 16, xl: 24, etc).
  • Radius: sm (4px), md (8px), lg (12px), xl (16px), full (9999px).

Animation & Interaction

  • Smooth, deliberate transitions (200–400ms cubic-bezier).
  • Minimal unnecessary motion.
  • Progress rings use SVG with stroke-dasharray for smooth animations.
  • Haptic feedback: light (20ms), medium (30ms), strong (50ms).

Component Architecture

  • Each screen is a self-contained Design Component (.dc.html).
  • Minimal dependencies. Portable across projects.
  • Ready for React/Vue/Svelte translation.
  • No build tools required. Render in browser immediately.

Navigation & State

  • Bottom tab navigation on all main screens (4 tabs).
  • Header back button for modal/detail views.
  • Persistent state via localStorage (run playback, settings, etc).
  • No external routing; use HTML anchor links (#1a, #2b).

Next Steps for Engineering

Ready for Development Handoff

  • Phase 1: Implement design system tokens in your theme provider. Map colors, typography, spacing scales to CSS variables or design tokens.
  • Phase 2: Build reusable components (buttons, cards, inputs, progress rings) matching the library. Test dark/light modes thoroughly.
  • Phase 3: Integrate with your V2 backend. Connect readiness endpoints, live tracking, training plan APIs to each screen.
  • Phase 4: Implement animations, haptic feedback, and real-time data streams (GPS, heart rate, HRV).
  • Phase 5: Comprehensive testing on device. Verify motion feels smooth, dark mode is easy on eyes at night, light mode is readable outdoors.

Brand Voice & Tone

In Coaching Copy

Expert. Supportive. Science-backed. Explain the "why" behind recommendations. Use clear, confident language. Avoid jargon unless teaching it.

✓ "Your HRV shows good recovery. Perfect for a tempo run today."

✗ "Your metrics look optimal bro. Send it."

In UI Labels & CTAs

Direct. Action-oriented. Avoid cute or flippant language. Respect user's time and intelligence.

✓ "Start Run" · "View Details" · "Edit Workout"

✗ "Let's Go!" · "Tap Me!" · "More Info Plz"
