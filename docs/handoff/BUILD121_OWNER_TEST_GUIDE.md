# Build 121 focused device checks

1. In Workout Intelligence, actual Auto-pause runs/rides switches should be separate from voice announcements. Change one, reopen Settings and confirm the sport choices persist independently.
2. During an active or paused workout, browse elsewhere and tap Live. The same session/time should return; a paused workout stays paused. Back/Home should still work.
3. Expand Everyday energy equivalent and Calculation details, including with larger text. Text should stay inside the card.
4. Keep the existing goal unchanged. Review a separate new goal when convenient: lifting experience is separate from running; time/equipment fit sessions; the week leaves recovery room. Saved beginner paths retain their dated sessions/recovery weeks.
5. Complete one strength set, then use Adjust exercise. Easier/harder actions affect remaining targets. A replacement keeps the performed original set, adds only remaining work and starts its own load calibration. Future choices are opt-in and resettable. Check both weight-unit settings.
6. In a real saved app run, Faster-work report should be collapsed. Report only work actually completed, if desired. Save/remove should be clear. Missing interval evidence keeps new prescriptions conservative; invented reports are not needed.

An eligible 4×4 path is covered by integrated synthetic fixtures. It is not expected in a beginner/unqualified account, and no hard workout or subscription repurchase is needed for these UI checks. Device acceptance, purchase lifecycle and public-launch readiness remain separate.
