# Build 123 exercise library, custom workouts and recorded volume

The shared metadata catalog covers 205 named exercise variants, including the current 42 generated strength definitions, every exercise row in 50 presets (182 rows, 67 distinct names), and all 24 mobility exercises used by 50 mobility routines. Known names receive plain-language setup, purpose, primary muscle or mobility-target tags, supporting muscles and equipment metadata. Existing exercise IDs remain intact. Equipment variants retain separate names and identities; aliases join spelling/abbreviation equivalents rather than transferring load between variations. The searchable exercise store merges these definitions with retained user-created entries. A typed unfamiliar custom name remains available without invented muscle attribution.

The expansion fills practical machine, cable, supported, bodyweight and free-weight choices for active adults, runners and hybrid trainees. Its count is a coverage result, not a ranking or an attempt to maximize exercise variety. The 205 name variants include aliases; the searchable catalog removes equivalent spelling duplicates. Machines, bands and simpler supported variations are legitimate tools. Existing program/preset/mobility selection and dose review is recorded separately by the programming lane. New library entries do not automatically add sets or change a person's plan.

Custom workouts now support exercise search, native iOS wheel filters for focus, muscles and equipment, per-exercise usage references, and a quiet Weekly muscle work disclosure. A known selection carries its stable canonical ID through the active reducer, saved completion and historical summary. Same-name equipment context is required before a display-only prior load/effort reference appears. Ambiguous equipment variants ask the athlete to choose equipment; reference weights are not silently transferred between barbell, dumbbell or machine setups.

Recorded volume uses completed, non-warm-up sets with a reported repetition, hold or distance. The calendar window is local Sunday–Saturday, matching the app. Backdated custom logs use their performed date, while preserving their later entry timestamp in the original record. Duplicate saved IDs and explicit per-set IDs do not inflate counts; distinct legacy sets without IDs are not silently merged. Primary and supporting sets remain separate. A squat contributes direct quadriceps/glute sets, not a full direct hamstring set. Power, balance, mobility and capacity-assessment practice remain separate from strength sets. A drop-set sequence counts once toward working-set attribution, with stages reported separately. These are recorded movement-set descriptions, not measured muscle activation, equal hypertrophy dose, or proof that the reported effort met a “hard set” threshold. No universal weekly target or automatic extra training is imposed. Unknown exercises contribute an unclassified count rather than fabricated muscle credit.

Select / More actions can pair two exercises as a superset or link two or more as a circuit. A drop set is a same-exercise sequence of separately recorded stages. Completed set records remain intact, new stages start unchecked, and duplicate-set actions clear current actual RPE/RIR. Group labels use athlete-facing ordinals rather than internal IDs. The flame control is explicitly named Warm-up. The custom workout title can wrap instead of shrinking into one line.

Saved workouts are named templates in an explicitly owner-scoped local repository. Reads and queued writes require current owner leases, validate nested data, merge fresh disk state, snapshot save intent, and confirm readback before reporting success. Read, parse, storage or owner failures keep existing bytes and the active workout available. The prefix participates in ownership discovery and verified account deletion. The saved list refreshes on focus, fences stale reads, and waits for strength-history hydration before starting. First-save binding preserves the template link through strength-log migration. Starting a saved workout creates fresh session/exercise/set/group IDs, shows previous actual performance separately, clears current actual RPE/RIR and all completion flags, and preserves named template structure. Historical quantities seed editable targets only for the same canonical exercise, template exercise slot and equipment. Extra actual sets do not silently expand the next template. Repeated partial/skipped sessions do not erase the last matching actual reference.

The new template repository is local to this device; this change does not claim cloud template backup or multi-device template synchronization. Existing strength completion logs still use the existing account-scoped synchronization path and retain additive group/template references in their JSON data. No database schema, server policy, image asset or native Watch code was changed by this lane.

The exercise guide review also replaces rigid shin-angle/depth and knee-travel rules, unsupported injury-protection guarantees, maximal-load claims and universal progression thresholds with controllable setup, tolerated range, individual effort and recovery language. A supported variation is an option, not a diagnosis or a mandatory rehabilitation pathway. Norwegian intervals, race specificity, progression/regression and multi-goal scheduling remain the separate programming engine's responsibility.

Primary and authoritative sources checked November 20, 2026:

- [ACSM 2026 resistance-training position stand](https://doi.org/10.1249/MSS.0000000000003897): individualization and progressive resistance training across different equipment and experience levels. Its outcome-level findings do not establish a universal per-muscle set target for every runner.
- [NSCA Romanian deadlift technique](https://www.nsca.com/education/articles/kinetic-select/romanian-deadlift-rdl/): hip-hinge setup and controlled knee position. Setup descriptions here are original concise coaching text.
- [NSCA Basics of Strength and Conditioning](https://www.nsca.com/contentassets/116c55d64e1343d2b264e05aaf158a91/basics_of_strength_and_conditioning_manual.pdf): exercise roles and technique context.
- [NASM exercise library](https://www.nasm.org/resource-center/exercise-library): applicable exercise, equipment and body-area coverage; its library is a discovery reference, not a claim of clinical validation or superiority.
- [ACE beginner exercise library](https://www.acefitness.org/resources/everyone/exercise-library/experience/beginner/?page=5): machine press, leg press, leg extension and pulldown options.
