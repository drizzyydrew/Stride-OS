# Build120: AI Coach usage

Update in TestFlight without uninstalling or clearing data. No new subscription purchase is needed.

1. Open AI Coach > Ask Coach. A small collapsed row above Your Training Context shows your requests used today. On a slow connection it checks usage first; it must not pretend an unknown reading is0.
2. Expand the row. Check the personal remaining allowance, local reset time (00:00UTC), example, explanation of failed requests, shared availability and Refresh usage. Collapse it again. Check larger text if normally used; chat input and navigation must stay reachable.
3. If you want to send a normal coaching message, note the count first. After the request is accepted, the refreshed server count should reflect one use, including a follow-up as another use. A provider failure may still count under the existing policy. Do not send20 messages just to exhaust it.
4. Leave and reopen chat, then close/reopen the app. The server reading should persist for your account, rather than resetting locally.
5. Optional network check: disconnect, then refresh usage. It should say unavailable or last checked; reconnect and refresh to recover. Recording/history/Insights remain available.

This is a new counter check only. Do not repeat the accepted118 checklist or119 logo check unless a new problem appears. Public release and subscription/provider lifecycle acceptance remain separate.
