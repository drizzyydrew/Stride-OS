# Build 38 Prototypes

These 22 high-fidelity prototype images use the current StrideOS dark-premium
tokens and document the approved Build 38 interaction contracts. The source is
`prototypes.html`.

The images were rendered from the static HTML source with macOS Quick Look.
They are design evidence, not simulator screenshots. Physical-device review
remains required for native camera, GPS, speech, MapKit, ActivityKit, Dynamic
Island, Lock Screen, StandBy, gestures, and accessibility behavior.
