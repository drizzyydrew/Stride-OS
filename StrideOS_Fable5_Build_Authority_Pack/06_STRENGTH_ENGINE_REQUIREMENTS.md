# Strength Engine Requirements

The strength system should feel like Garmin plus 5/3/1 plus a physical therapist.

It should not feel like random exercises.

## Core Goals

- Build durability for running.
- Improve strength without sabotaging endurance.
- Track progressive overload.
- Preserve all workout history.
- Make the next set and next session obvious.

## Required Tracking

- Exercise history
- Sets
- Reps
- Weight
- RPE
- Session duration
- Session load
- Progression over time

## Exercise Library

Each exercise should include:

- name
- category
- main muscles
- image or visual reference
- start position
- finish position
- how to perform
- coaching tips
- common mistakes
- when to use it

## Session UX

During a workout, the athlete should know:

- current exercise
- next exercise
- current set
- total sets
- selected weight
- selected RPE
- what to do next

Every set completion should save.

Every weight/RPE input should persist.

Do not lose previous workout history.

## Progression Logic

When possible, suggest progression based on:

- previous load
- completed reps
- RPE
- consistency
- readiness
- running load

Avoid pushing heavy progression after high run load or low readiness.
