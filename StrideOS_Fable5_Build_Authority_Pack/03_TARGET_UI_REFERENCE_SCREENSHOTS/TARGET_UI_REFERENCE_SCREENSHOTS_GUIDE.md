# Target UI Reference Screenshots

These images are references for direction, not pixel-perfect requirements.

Use them to understand the desired quality bar:

- premium dark-first StrideOS aesthetic
- simple readable run screens
- clear Live Activity / Lock Screen metrics
- hydration recommendations with rationale
- map-first route/run experiences
- AI Coach in dark and light modes

Do not copy external brands directly.

Extract the useful principles:

- readability
- hierarchy
- calm athletic polish
- strong action clarity
- decision-oriented coaching

The final app should feel like StrideOS, not a collage of references.
